# 蘋果五線譜 Apple Picking — 拖曳認譜遊戲

仿照 [Dr. Musik "Apple Picking"](https://www.doctormusik.com/apps-and-games/apple-picking/) 重製的網頁小遊戲：
**000 首頁** → **001 設定頁**選好練習音域 → **01 遊戲頁**把樹上的蘋果拖到五線譜的正確位置，摘滿 **10 顆**過關。

* 線上玩：`https://<你的帳號>.github.io/<repo>/`
* 離線版：`dist/apple-picking.html`（單檔，雙擊即可開）
* 作者：[Threads @lycbert](https://www.threads.com/@lycbert) ・ [YouTube @datoemusic](https://www.youtube.com/@datoemusic)

## 快速開始（發佈到 GitHub Pages）

```bash
# 1. 在 GitHub 建一個新的 repository（例如 apple-picking），不要勾選初始化 README
# 2. 解開封包後，在資料夾內執行
git init
git add .
git commit -m "蘋果五線譜 Apple Picking：首頁／設定／遊戲三頁認譜遊戲"
git branch -M main
git remote add origin https://github.com/<你的帳號>/apple-picking.git
git push -u origin main
```

發佈網站：Repo → **Settings → Pages** → Source 選 `Deploy from a branch`、Branch 選 `main` / `/ (root)` → Save。
約一分鐘後即可用 `https://<你的帳號>.github.io/apple-picking/` 開啟（根目錄 `index.html` 就是遊戲入口）。

> 遊戲完全不需要後端，也不會發出任何網路請求（注音字型、插畫、音效全部內嵌或以程式合成），
> 直接放進任何靜態空間（GitHub Pages、Netlify、Cloudflare Pages、學校網站）都能跑。

```bash
python3 build.py        # → dist/apple-picking.html
```

改完請把 `index.html`、`src/` 與 `dist/apple-picking.html` 一起 commit，線上的開發版與離線單檔才會一致。

## 001 設定頁

* 版面分成四塊、全部左右對齊：**標題**（上）→ **五線譜卡片**（中）→ **出題設定卡片**（左下，固定標籤欄＋等寬晶片）→ **譜號與開始卡片**（右下）。
* **點蘋果**＝開／關這個音，選中的蘋果會亮起來；上方膠囊即時顯示範圍、音數與目前設定摘要（例：`中音域 範圍 C – B 7 個音 | 音名・10 顆過關・彩色・聲音開`）。
* 想一次刷一整排時，先按右側 **連續刷選** 再按住拖曳（預設關閉，避免誤掃）；每次操作都會跳出大字提示（例：`記號：♯ 升`、`已重設：回到中央 Do–Si`）。
* 每次進入設定頁，預設開啟的音域是 **中央 Do（C4）– Si（B4）** 這 7 個音；
  切換譜號時會自動換算成該譜號的位置（高音譜號在第三線下方一帶、低音譜號在五線譜上方）。
* **譜號**：高音譜號 / 低音譜號（紅色卡片為目前選用）。
* **選項**：
  * ~~模式~~：已移除；**每一場固定摘滿 10 顆過關**（樹上會持續長蘋果，摘滿 10 顆即結算）
  * 標示：`音名 C`／**`注音 ㄉㄛ`**／`唱名 Do`
    * 注音＝台灣音樂課本的注音唱名，**固定調**：C ㄉㄛ、D ㄖㄨㄝ、E ㄇㄧ、F ㄈㄚ、G ㄙㄛ、A ㄌㄚ、B ㄒㄧ
    * 直排於蘋果上（聲符／韻符分列，例：ㄉ ㄨㄛ），並附內嵌子集字型，離線也看得到
    * 音域膠囊、提示、錯誤訊息都會同步顯示同一種標示；**一律不顯示八度數字**（例：`ㄉㄛ – ㄒㄧ`、`C – B`）
  * 蘋果：`彩色`（C 紅、D 橘、E 黃、F 綠、G 藍綠、A 紫、B 桃紅）／`紅色`
  * 聲音：`開`／`關`
  * 記號：`無`／`♯ 升`／`♭ 降`（練習升記號、降記號）
  * 音域（動作鈕，按一下立即生效、不會停在「已選」狀態）：`全選`（面板上全部 17／14 個音）／`只看譜內`（五線譜上的 9 個音）／`不限`（清空勾選，面板上所有位置都會出題）
* 右下 **譜號與開始**卡片：兩張譜號卡 → **開始！**（按鈕上顯示 `高音譜號・C – B`）→ 小按鈕列 **怎麼玩？／↺ 重設**（回到中央 Do–Si、彩色、聲音開、無記號）與 **連續刷選** 開關。

## 01 遊戲頁

* 樹上同時最多 6 顆蘋果，摘掉會再長。
* **拖曳**蘋果到五線譜即可；也可以**先點蘋果、再點譜面**（適合觸控或精細動作較弱的孩子）。
* 拖曳時會出現**黃色落點提示條**與加線預覽；右上 💡 打開後還會顯示該位置的音名。
* 放對：蘋果吸到譜上、播放該音、綠色勾勾＋星火、＋1。
* 放錯：扣一顆愛心、畫面震動、提示「再想想～ 這是 X」；同一個音錯第二次會直接標出正確位置。
* 連對 5 顆補回一顆愛心；愛心用完或摘滿 10 顆 → 結算（答對、失誤、正確率、最高連對＋星等，並把譜上的蘋果播成一段小旋律）。
* 右下工具：`▶ 聽旋律`、`顯示答案`、`提早結束`；右上：音效、提示、重玩、回設定。

## 幾個實作重點

**五線譜座標**
以「第三條線」為基準，`step = 4` 就是第三線，每上升半格（線→間）＋1；
s=0 為最下面那條線。高音譜號 s=0 = E4、s=4 = B4；低音譜號 s=0 = G2、s=4 = D3。
超過 5 條線的音會自動畫加線（ledger lines）。

**音域與版面（以中央 Do–Si 為基準的箭頭）**
以**固定的音域概念「中央 Do（C4）～ Si（B4）」**貫穿全作，設定頁預設就是這 7 個音。
蘋果標示的箭頭規則（`T.triOf()`，與譜號無關，只看實際音高）：

| 實際音高 | 標示 | 例子 |
| --- | --- | --- |
| 中央 Do – Si（C4–B4） | **不標** | `C4` `E4` `A4` `B4` |
| 低於中央 Do | **▽** | 低音譜中比中央 Do 低的 A、B 等音（例：低音譜的 `ㄌㄚ▽`、`ㄒㄧ▽`） |
| 高於中央 Si | **▲** | 高音譜中比中央 Si 高的音（例：高音譜的 `ㄉㄛ▲`、`ㄇㄧ▲`） |

箭頭畫在蘋果名字右上角（`AP.core.triMarkup()` 的向量三角形，不依賴字型），
注音／唱名模式也一樣；範圍膠囊、提示氣泡、答錯訊息會同步顯示（例：`A▽ – C▲`、`ㄌㄚ▽ – ㄉㄛ▲`），且**不顯示八度數字**。
設定頁每個譜號可選的位置分別是
高音譜 17 個（最下加三線以上 ～ 上加三線）、低音譜 14 個（**第一線 ～ 上加二間**），
低音譜不出第一線以下的音；五線譜面板與整串蘋果會依譜號重新垂直置中並自動調整面板高度，
低音譜的蘋果會稍微縮小，確保所有候選音都落在面板內。
低音譜只保留中央 Do–Si 中落在面板內的部分（中央 Do 起 4 個音）作為預設範圍。
遊戲頁的五線譜也會依譜號下移，讓中央 Do–Si 落在畫面中央，不需要大幅捲動視線。

**譜號與升降記號**
使用 SMuFL 標準字型 **Bravura** 的向量外框（`src/js/clefdata.js`），
1 em = 4 個線間距，高音譜號原點落在 G 線、低音譜號原點落在 F 線，比例與出版社樂譜一致。

**音高與音區（不顯示數字）**
`pitch.octave` 只在程式內部用來判定音高（高音譜 s=0 是 E4、低音譜 s=0 是 G2，C4＝中央 Do），
畫面上完全不輸出八度數字：蘋果上只有音名／注音／唱名加箭頭，範圍膠囊只寫音名範圍（例 `C – B`、`A▽ – C▲`），設定頁也沒有「八度」開關。
`T.registerOf()` 仍產生「低音域／中音域／高音域」色塊，作為顏色的輔助提示。

**注音唱名**
注音表放在 `theory.js` 的 `ZHUYIN`，可用 `AP.theory.nameText(pitch,'zhuyin')` 取得文字。
蘋果上的注音以 SVG 文字繪製，`splitZhuyin()` 會把 3 個符號以上的注音（如 `ㄖㄨㄝ`）斷成 `ㄖ` / `ㄨㄝ` 兩列，2 個符號（如 `ㄉㄛ`）維持一列，
字型用 `zyfont.js` 內嵌的 Noto Sans TC 子集（只含 37 個注音符號與 4 個調號，約 5 KB）。

**音色**
全部用 Web Audio 即時合成（三角波＋泛音＋低通衰減），不需要任何音檔，離線也能發聲。

**版面**
固定 16:10 的 1280×960 舞台，依視窗等比縮放並置中；
電腦、平板、手機橫放都可以直接玩；拖曳使用 Pointer Events，支援滑鼠、觸控與觸控筆。

**電子白板最佳化**
* 按鈕全面放大：選項晶片 54 px 高、字 19 px（1920×1080 投影時實際約 61 px／21 px），開始鈕 96 px 高、字 38 px；次要按鈕 50 px。
* 選項重新分組：`標示`（音名／注音／唱名）在最前，`音域` 的三個動作鈕獨立成組、改用方形藍灰外觀，和「會保持選取」的選項鈕明確區隔。
* 對比全部達 WCAG AA：選取晶片 4.66:1、開始鈕 4.58:1、範圍膠囊灰字 5.5:1（原本 2.98:1）、譜號標籤 6.1:1。
* 點蘋果改用「最近的蘋果中心」判定，命中半徑 44 px；相鄰蘋果重疊時也不會點到隔壁（17 顆全部逐點驗證通過）。
* 停用雙擊縮放（`touch-action` + meta viewport），白板上不會誤觸放大。
